# Что считается оператором и операндом в анализаторе Холстеда (Kotlin)

Документ описывает **фактические правила** программы `halstead_analyzer_kotlin_gui_final.py`.
Все примеры в таблицах получены прогоном через сам анализатор, поэтому их можно сравнивать
с ручным подсчётом. Если результат в программе и в документе расходится – это баг.

## 0. Как работает подсчёт

1. **Комментарии** (`// ...` и `/* ... */`) удаляются, строки и символьные литералы не затрагиваются.
2. Текст разбивается на **токены**: строки, числа, идентификаторы, знаки, скобки. Пробелы и переводы строк игнорируются.
3. Токены обрабатываются **слева направо**, каждый токен попадает в одну из трёх категорий: оператор, операнд или «не считается».
4. Считаются частоты. Одинаковые операторы (или операнды) объединяются в одну строку таблицы.

| Метрика | Что это | Как считается |
|---|---|---|
| η₁ | число различных операторов | число строк в таблице операторов |
| η₂ | число различных операндов | число строк в таблице операндов |
| N₁ | общее число операторов | сумма частот f₁ⱼ |
| N₂ | общее число операндов | сумма частот f₂ᵢ |
| η | словарь программы | η₁ + η₂ |
| N | длина программы | N₁ + N₂ |
| V | объём программы | N · log₂(η) |

Проверка: сумма всех частот в таблице операторов должна равняться N₁, в таблице операндов – N₂.

## 1. Шпаргалка: «токен → куда попадает»

| Что встретилось | Куда | Как записывается в таблице |
|---|---|---|
| Ключевое слово (`if`, `val`, `return`, `private` …) | оператор | само слово |
| Знак операции (`+`, `=`, `==`, `&&`, `?.`, `..` …) | оператор | сам знак |
| Точка `.`, двоеточие `:`, точка с запятой `;`, `?`, `@` | оператор | сам знак |
| Идентификатор с `(` сразу за ним: `f(...)` | оператор | `f()` |
| Идентификатор с `{` сразу за ним (вызов с лямбдой) | оператор | `f()` |
| Пара скобок `( )` не в вызове и не в заголовке `if/for/while/when/catch` | оператор | `()` |
| Пара `{ }` (тело функции, класса, лямбда, блок) | оператор | `{}` |
| Пара `[ ]` | оператор | `[]` |
| Инфиксное слово между операндами (`and`, `or`, `xor`, `shl`, `shr`, `ushr`, `until`, `downTo`, `step`, `to`) | оператор | само слово |
| Остальной идентификатор (переменная, параметр, тип, имя члена, имя класса в объявлении) | операнд | само имя |
| Число, строка, символ | операнд | как записано |
| `true`, `false`, `null` | операнд | само слово |
| Текстовый кусок строкового шаблона | операнд | кусок в кавычках |
| Запятая, комментарии, метки, `$` и `{ }` шаблона, пробелы | **не считается** | – |

## 2. Операторы

### 2.1 Ключевые слова (каждое слово – отдельный оператор)

| Группа | Слова |
|---|---|
| Управление потоком | `if`, `else`, `when`, `for`, `while`, `do`, `try`, `catch`, `finally`, `break`, `continue`, `return`, `throw` |
| Проверки и приведение типов | `in`, `is`, `as` |
| Объявления | `fun`, `val`, `var`, `class`, `interface`, `object`, `enum`, `typealias`, `package`, `import`, `constructor`, `init`, `companion`, `data`, `const` |
| Модификаторы | `abstract`, `actual`, `annotation`, `crossinline`, `expect`, `external`, `final`, `infix`, `inline`, `inner`, `internal`, `lateinit`, `noinline`, `open`, `operator`, `out`, `override`, `private`, `protected`, `public`, `reified`, `sealed`, `suspend`, `tailrec`, `vararg` |
| Прочие | `this`, `super`, `by`, `where` |

Дополнительно `as?` (безопасное приведение) считается **одним** оператором.
Все ключевые слова считаются отдельно: `if` и `else`, `do` и `while`, `for` и `in`, `try`, `catch`, `finally` – это разные операторы, составные конструкции **не объединяются** в один оператор.

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `if (a > 0) b = 1 else b = 2` | `if`, `>`, `=` ×2, `else` | `a`, `0`, `b` ×2, `1`, `2` | `if` и `else` – два отдельных оператора; скобки заголовка `if (...)` не считаются |
| `do { i++ } while (i < 3)` | `do`, `++`, `{}`, `while`, `<` | `i` ×2, `3` | `do` и `while` – отдельные операторы |
| `for (i in 1..3) {}` | `for`, `in`, `..`, `{}` | `i`, `1`, `3` | `for` и `in` – отдельные; `{}` – пара скобок |
| `try { f() } catch (e: Exception) { g() } finally { h() }` | `try`, `f()`, `{}` ×3, `catch`, `:`, `g()`, `finally`, `h()` | `e`, `Exception` | `try`, `catch`, `finally` отдельно; скобки `catch (...)` не считаются |
| `when (x) { 1 -> a() else -> b() }` | `when`, `->` ×2, `a()`, `else`, `b()`, `{}` | `x`, `1` | `when`, `->`, `else` отдельно; `{}` – один оператор |
| `return@forEach` | `return` | — | метка `@forEach` не считается, `return` считается |

### 2.2 Знаки операций и разделители

Один токен – один оператор. Составные знаки (`+=`, `==`, `?.`, `!!`, `->` …) считаются **одним** оператором.

| Группа | Знаки |
|---|---|
| Арифметика | `+` `-` `*` `/` `%` |
| Присваивание | `=` `+=` `-=` `*=` `/=` `%=` `&=` `\|=` `^=` |
| Инкремент / декремент | `++` `--` |
| Сравнение | `==` `!=` `===` `!==` `<` `>` `<=` `>=` |
| Логика | `&&` `\|\|` `!` |
| Работа с null | `?.` `?:` `!!` `?` |
| Ссылки, типы, лямбды | `::` `:` `->` |
| Диапазоны | `..` `..<` |
| Обращение к члену | `.` |
| Разделитель | `;` |
| Аннотация | `@` |
| Одиночные `&` `\|` `^` `~` | считаются, если встретятся |

Особые решения:
- `!in` и `!is` разбиваются на **два** оператора (`!` + `in`, `!` + `is`), как `Not` и `In` в таблице 1 методички.
- `!=` остаётся **одним** оператором (аналог `<>`).
- `-` считается одинаково в вычитании и в унарном минусе: `-7` = оператор `-` + операнд `7`.
- Точка `.` – отдельный оператор при обращении к члену. Точка внутри числа (`0.0001`) – часть числа.
- `<` и `>` в дженериках считаются как обычные знаки.

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `a + b - c * d / e % f` | `+`, `-`, `*`, `/`, `%` | `a`, `b`, `c`, `d`, `e`, `f` | арифметика: каждый знак – оператор |
| `x = 1` | `=` | `x`, `1` | присваивание |
| `x += 2; y -= 1` | `+=`, `;`, `-=` | `x`, `2`, `y`, `1` | составное присваивание – один оператор; `;` тоже оператор |
| `i++; j--` | `++`, `;`, `--` | `i`, `j` | инкремент и декремент |
| `a == b` | `==` | `a`, `b` | сравнение; так же `!=`, `<`, `>`, `<=`, `>=`, `===`, `!==` |
| `a && b \|\| c` | `&&`, `\|\|` | `a`, `b`, `c` | логические И / ИЛИ |
| `!flag` | `!` | `flag` | отрицание `!` – отдельный оператор |
| `x !in list` | `!`, `in` | `x`, `list` | `!in` = два оператора: `!` и `in` |
| `o !is String` | `!`, `is` | `o`, `String` | `!is` = два оператора: `!` и `is` |
| `a != b` | `!=` | `a`, `b` | `!=` – ОДИН оператор (как `<>` в Pascal) |
| `-7` | `-` | `7` | унарный минус: оператор `-` и операнд `7` |
| `1..10` | `..` | `1`, `10` | диапазон `..`; для `..<` то же |
| `v?.length` | `?.` | `v`, `length` | `?.` – отдельный оператор |
| `v ?: 0` | `?:` | `v`, `0` | элвис `?:` |
| `s!!.length` | `!!`, `.` | `s`, `length` | `!!` – один оператор, затем `.` |
| `x.y` | `.` | `x`, `y` | точка – отдельный оператор |
| `val s: String? = null` | `val`, `:`, `?`, `=` | `s`, `String`, `null` | `:` и `?` – операторы; `null` – операнд |
| `::fib` | `::` | `fib` | ссылка на функцию `::` |
| `{ a, b -> a * b }` | `->`, `*`, `{}` | `a` ×2, `b` ×2 | `->` – оператор; пара `{}` – один оператор |
| `@Test fun f() {}` | `@`, `fun`, `f()`, `{}` | `Test` | аннотация: `@` – оператор, `Test` – операнд |
| `val n = 0.0001` | `val`, `=` | `n`, `0.0001` | десятичная точка внутри числа – не оператор |

### 2.3 Вызовы функций

Идентификатор, за которым сразу идёт `(` (или `{` для вызова с лямбдой, или `<...>(` для вызова с типом), считается **одним оператором** вида `имя()`. Скобки самого вызова отдельно **не** считаются. Это относится и к объявлениям функций и конструкторов, и к созданию объектов.

Исключения для `{`: имя не считается вызовом, если перед ним стоит `:` `,` `class` `object` `interface` `enum` `typealias` (это объявление типа, например `class A : B {`).

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `println(x)` | `println()` | `x` | вызов = один оператор `println()`; скобки вызова отдельно не считаются |
| `f(g(x))` | `f()`, `g()` | `x` | два вызова = два оператора |
| `fun add(a: Int, b: Int): Int { return a + b }` | `fun`, `add()`, `:` ×3, `return`, `+`, `{}` | `a` ×2, `Int` ×3, `b` ×2 | имя в объявлении тоже даёт `add()` |
| `class Point(val x: Int)` | `class`, `Point()`, `val`, `:` | `x`, `Int` | конструктор/объявление: `Point()` |
| `Point(1, 2)` | `Point()` | `1`, `2` | создание объекта – тоже вызов |
| `list.forEach { println(it) }` | `.`, `forEach()`, `println()`, `{}` | `list`, `it` | вызов с лямбдой без скобок: `forEach()` |
| `mutableListOf<Int>()` | `mutableListOf()`, `<`, `>` | `Int` | вызов с типом: `mutableListOf()`; `<` и `>` считаются отдельно |
| `x.y.z()` | `.` ×2, `z()` | `x`, `y` | `.` ×2, `z()`; `x` и `y` – операнды |
| `readLine()?.toIntOrNull()` | `readLine()`, `?.`, `toIntOrNull()` | — | `readLine()`, `?.`, `toIntOrNull()` – три оператора |
| `@Named("x") val v = 1` | `@`, `Named()`, `val`, `=` | `"x"`, `v`, `1` | аннотация с аргументом: `@` и `Named()` |

### 2.4 Парные скобки

- Пара `( )`, `{ }` или `[ ]` считается **одним оператором**, при этом он засчитывается в момент **закрывающей** скобки. Открывающая и закрывающая скобки отдельно не считаются.
- **Не считаются** скобки вызова `f( )` и скобки заголовков `if ( )`, `for ( )`, `while ( )`, `when ( )`, `catch ( )`.
- Все остальные `( )` – группа, оператор `()`.
- Все `{ }` считаются, включая тело функции, класса, `if`, `when`, лямбду.

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `val y = (a + b) * c` | `val`, `=`, `+`, `()`, `*` | `y`, `a`, `b`, `c` | группа `( )` вне вызова – один оператор `()` |
| `if (a && (b \|\| c)) {}` | `if`, `&&`, `\|\|`, `()`, `{}` | `a`, `b`, `c` | скобки `if (...)` не считаются, вложенные `(b || c)` – считаются |
| `val (a, b) = pair` | `val`, `()`, `=` | `a`, `b`, `pair` | деструктуризация: `()` считается как обычная группа |
| `return (a + b)` | `return`, `+`, `()` | `a`, `b` | после `return` скобки – группа |
| `val f: (Int) -> Int = { it }` | `val`, `:`, `()`, `->`, `=`, `{}` | `f`, `Int` ×2, `it` | тип функции `(Int)` – группа `()`; `{}` – лямбда |
| `arr[i]` | `[]` | `arr`, `i` | пара `[ ]` – один оператор `[]` |
| `fun f() { g { h() } }` | `fun`, `f()`, `g()`, `h()`, `{}` ×2 | — | каждая пара `{ }` – отдельный оператор `{}` (тело функции, лямбда) |
| `class A { }` | `class`, `{}` | `A` | тело класса – `{}` |

### 2.5 Инфиксные слова

`and`, `or`, `xor`, `shl`, `shr`, `ushr`, `until`, `downTo`, `step`, `to` считаются операторами (аналог `And`, `Or`, `Xor`, `Shl`, `Shr` из таблицы 1), **только** когда стоят между двумя операндами (слева – идентификатор, число, `)` или `]`; справа – идентификатор, число или `(`). Иначе это обычные идентификаторы (операнды).

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `(a and b) or (c xor d) shl 1` | `and`, `()` ×2, `or`, `xor`, `shl` | `a`, `b`, `c`, `d`, `1` | `and`, `or`, `xor`, `shl` – операторы между операндами |
| `for (i in 10 downTo 1 step 2) {}` | `for`, `in`, `downTo`, `step`, `{}` | `i`, `10`, `1`, `2` | `downTo`, `step` – операторы |
| `val m = "k" to 1` | `val`, `=`, `to` | `m`, `"k"`, `1` | `to` – оператор |
| `val step = 2 ⏎ val to = step + 1` | `val` ×2, `=` ×2, `+` | `step` ×2, `2`, `to`, `1` | переменные с такими именами – операнды |
| `x.to(1)` | `.`, `to()` | `x`, `1` | после точки – обычный вызов `to()` |

## 3. Операнды

Операнд – это идентификатор, который не является ключевым словом, вызовом и инфиксным словом, а также любой литерал.

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `val count = total` | `val`, `=` | `count`, `total` | переменные `count`, `total` |
| `fun f(name: String, n: Int) {}` | `fun`, `f()`, `:` ×2, `{}` | `name`, `String`, `n`, `Int` | параметры и типы `name`, `String`, `n`, `Int` – операнды |
| `val a = 12; val b = 12` | `val` ×2, `=` ×2, `;` | `a`, `12` ×2, `b` | одинаковые числа – один операнд с частотой 2 |
| `val d = 2.5 + 0x1F + 100L + 1e3` | `val`, `=`, `+` ×3 | `d`, `2.5`, `0x1F`, `100L`, `1e3` | числа считаются как записаны: `2.5`, `0x1F`, `100L`, `1e3` |
| `val s = "abc"` | `val`, `=` | `s`, `"abc"` | строка целиком, вместе с кавычками, – один операнд |
| `val c = 'x'` | `val`, `=` | `c`, `'x'` | символьный литерал – операнд |
| `val t = true; val u = null` | `val` ×2, `=` ×2, `;` | `t`, `true`, `u`, `null` | `true`, `false`, `null` – операнды |
| `obj.name` | `.` | `obj`, `name` | `obj` и `name` – операнды, между ними оператор `.` |
| `Color.RED` | `.` | `Color`, `RED` | `Color` и `RED` – операнды |
| `it` | — | `it` | `it`, `field`, `value` – обычные идентификаторы, то есть операнды |

### 3.1 Строковые шаблоны

Строка **без** `$` – один операнд целиком (с кавычками). Строка с `$`: разбивается на текстовые куски (каждый – операнд в кавычках) и выражения (`$name` и `${...}`), которые разбираются как обычный код. Сами `$`, `${` и `}` не считаются. Пустых текстовых кусков не бывает.

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `"Сумма: $s"` | — | `"Сумма: "`, `s` | текст `"Сумма: "` – операнд, `s` – операнд; знак `$` не считается |
| `"Сумма: ${a + b} руб"` | `+` | `"Сумма: "`, `a`, `b`, `" руб"` | два текстовых куска-операнда и выражение `a + b` разобрано как обычный код; `${`, `}` не считаются |
| `"${f(1)}"` | `f()` | `1` | текста нет – только содержимое выражения: `f()` и `1` |
| `"n = ${g("x")}"` | `g()` | `"n = "`, `"x"` | вложенные кавычки работают |
| `"цена \$5"` | — | `"цена \$5"` | экранированный `\$` – обычный текст, вся строка – один операнд |

## 4. Что не считается вообще

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `val a = 1 // комментарий ⏎ /* блок */ val b = 2` | `val` ×2, `=` ×2 | `a`, `1`, `b`, `2` | комментарии удаляются до подсчёта |
| `f(a, b, c)` | `f()` | `a`, `b`, `c` | запятые не считаются |
| `outer@ for (i in 1..3) { continue@outer }` | `for`, `in`, `..`, `continue`, `{}` | `i`, `1`, `3` | метки `outer@` и `@outer` не считаются; `continue` и `for` считаются |
| `list.forEach { if (it == 0) return@forEach }` | `.`, `forEach()`, `if`, `==`, `return`, `{}` | `list`, `it`, `0` | `return` – оператор, `@forEach` – метка, не считается |
| `this@Main.name` | `this`, `.` | `name` | `this` – оператор; `@Main` – метка, не считается |

Также не считаются: запятые, пробелы, переводы строк, символы вне таблицы (например, `#`, `\`), `$` вне строки.

## 5. Спорные и проверенные случаи

| Код | Операторы | Операнды | Пояснение |
|---|---|---|---|
| `x !in list` | `!`, `in` | `x`, `list` | `!in` → `!` и `in` |
| `!index` | `!` | `index` | `!` и операнд `index` (не путается с `!in`) |
| `!isValid` | `!` | `isValid` | `!` и операнд `isValid` (не путается с `!is`) |
| `import kotlin.math.abs` | `import`, `.` ×2 | `kotlin`, `math`, `abs` | `import` – оператор, `.` ×2 – операторы, три имени – операнды |
| `package demo.app` | `package`, `.` | `demo`, `app` | аналогично `import` |
| `if (a < b) x = 1` | `if`, `<`, `=` | `a`, `b`, `x`, `1` | `<` – сравнение, а не дженерик (нет `>` и `(` после него) |
| `val l: List<Int> = x` | `val`, `:`, `<`, `>`, `=` | `l`, `List`, `Int`, `x` | `<` и `>` в дженерике тоже считаются операторами |
| `constructor(x: Int) {}` | `constructor`, `:`, `()`, `{}` | `x`, `Int` | после `constructor` скобки – группа `()` (исключения только для `if/for/while/when/catch`) |
| `class A : B, C { }` | `class`, `:`, `{}` | `A`, `B`, `C` | запятая не считается; `A`, `B`, `C` – операнды, `:` – оператор |

## 6. Пример для ручной проверки

Код (13 строк). Скопируйте его в программу и сравните результат.

```kotlin
fun digitSum(number: Int): Int {
    var n = abs(number)
    var sum = 0
    do {
        sum += n % 10
        n /= 10
    } while (n > 0)
    return sum
}
fun main() {
    val x = readLine()?.toIntOrNull() ?: -1
    if (x !in 0..9) println("Ошибка: $x") else println(digitSum(x))
}
```

## 7. Как проверять вручную

1. Выпишите код без комментариев.
2. Пройдите строку слева направо и для каждого токена решите по шпаргалке из раздела 1.
3. Не забудьте, что `f(x)` – это **один** оператор `f()`, а `x` внутри – отдельный операнд.
4. Пары скобок считайте один раз (на закрывающей), кроме скобок вызова и заголовков `if/for/while/when/catch`.
5. Ключевые слова считайте **по одному** (`if` и `else` – два оператора).
6. Сложите частоты и проверьте: сумма по операторам = N₁, сумма по операндам = N₂.
7. Посчитайте η = η₁ + η₂, N = N₁ + N₂, V = N · log₂(η).

## 8. Известные ограничения

- Классификация опирается на форму записи, а не на типы: `x.size` даёт операнды `x` и `size` (свойство), а `x.size()` – оператор `size()`.
- Идентификатор перед `{` считается вызовом с лямбдой, кроме случаев после `:` `,` `class` `object` `interface` `enum` `typealias`; редкие конструкции (`class A : B by c {`) могут посчитаться иначе.
- Внутри `${...}` строка с вложенным `$` считается целым операндом, дальше не разбирается.
- В Kotlin точка с запятой почти не встречается, поэтому оператор `;` в таблице бывает редко или не бывает совсем.
- `package` и `import` считаются как обычный код.
